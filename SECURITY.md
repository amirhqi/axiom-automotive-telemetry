# Security policy

## Scope

AXIOM is an engineering/portfolio telemetry project and is not safety-certified. Do not use it as a safety-critical vehicle component or as the sole source for safety decisions.

## Reporting a vulnerability

Please avoid publishing a suspected vulnerability as a public issue when it could expose users or systems. Use GitHub private vulnerability reporting when available, or contact the maintainer privately through the repository owner profile.

Include:

- Affected version/commit
- Reproduction steps
- Expected vs. observed behavior
- Potential impact
- Suggested mitigation, if known

Security reports will be reviewed before public disclosure.
